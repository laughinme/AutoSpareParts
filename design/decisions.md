# Решения

- Светлый графитово-зелёный интерфейс: читаемость каталога и спокойное рабочее пространство. Пользователь разрешил свободно выбирать дизайн и палитру.
- Единая система для покупателя, продавца и администратора через общие токены и компоненты.
- Поиск в отдельной просторной строке, навигация под ним: больше места для артикула и длинных названий.
- Марка выбирается из существующего справочника API, без ввода ID.
- Никаких новых бизнес-обещаний: панель гаража ведёт к существующему гаражу; товар показывает только данные API.
- Mobbin исследование ограничено тарифом: не приписываем ему дизайн-решения без доступных экранов.
- Кабинет продавца использует totals существующего API товаров по статусам. Удалён стартовый экран с фиктивной аналитикой.
- На телефоне информация о товаре и покупка идут сразу после фотографии; описание ниже характеристик.
- При проверке исправлены существовавшие ошибки типов: параметры onSettled в гараже, nullable cursor, сигнатура Stripe onExit, обращение к отсутствующему setComponentLoading и тип массива Vite plugins.

## Редизайн веб-интерфейса от 5 ноября 2026

- Графитовый первый экран с фотографией тормозного узла задаёт визуальный характер. Светлый каталог, плотная сетка и спокойные границы помогают сравнивать товары.
- Поиск отделён от черновика фильтров. Быстрый выбор состояния сохраняет текущий запрос. На телефоне фильтры открываются рядом с переключателями состояния.
- У корзины отдельная сводка с суммой доступных к оформлению товаров. Список может дополнительно показывать недоступные позиции.
- Оформление входа, карточки товара, гаража и рабочих разделов опирается на общие цвета, типографику и элементы управления.
